# 90 秒演示分镜

1. 0–12 秒：质量概览。说明目标用户是 Agent 产品和质量人员，指标来自当前样本实际计算。
2. 12–25 秒：打开数字错误。指出回答 1380 与证据字段 1280 不一致，展示时间与请求编号。
3. 25–40 秒：人工复核。填写生成引用错误及改进建议，保存后查看记录。
4. 40–52 秒：切换候选版本。检查修订数字，不把“规则未命中”当作完整质量通过。
5. 52–66 秒：版本实验。比较一致率时同时观察覆盖率；说明是预置回答对照。
6. 66–78 秒：个性化治理。两种画像对同一事实产生不同数字，判定漂移。
7. 78–90 秒：数据连接。展示真实接口状态或明确失败原因，说明模型意见与人工结论分开。

展示中只使用构造用户与已脱敏信息。线上真实接口演示以实际授权和可调用工具为准。分镜视频不替代外部服务验证记录。
