# 验证证据索引与实验结论

本次补充验证在 2026-10-21 晚间进行，文档整理跨至 2026-10-22。开发和浏览器验收操作人为 Codex，不冒充候选人本人或独立人工评审。

## 真实修订 Prompt 实验

[公开实验摘要](evidence/prompt-summary.json)；完整输入、输出和逐断言复评在本地交付附件 `evidence/real-prompt-experiments.json`。3 道题 × 2 个 Prompt = 6 次实际 DeepSeek 调用，均 HTTP 200，实际返回模型均为 deepseek-flash，请求别名 deepseek-chat，temperature=0，max_tokens=2400。每道题固定问题、原回答、画像、热点上下文和同一证据快照；`snapshotSha256` 是这些输入的 SHA-256。原始 JSON 含完整模型响应、请求 ID、采样参数、模型版本、Prompt 名称、judge-2 审查配置版本和确定性复评。原始模型返回、精确调用时间与请求编号不公开发布；可在 `lib/judge.ts` 查看两个 Prompt 的确切共同约束与差异。

注意：比较对象是“审查员生成的修订草稿”，不是两个底层投资 Agent。输入中的价格和热点均为匿名构造数据，模型 API 调用是真实的。每题每臂只调用一次，顺序为 v1 后 v2，未随机排序，无重复采样与独立人工金标准，不能证明稳定提升或统计显著效果。

| 样本 | 复评结果 |
| --- | --- |
| QA-001 数字引用错误 | 两稿各提取 2 条数字断言，均一致，规则线索均 0 |
| QA-004 收益承诺 | 两稿各 2 条断言均一致；v1 有 1 条主题词线索，v2 为 0，仍需语义与边界复核 |
| QA-007 未核实热点 | 两稿均保留传闻不确定性，各 2 条数字断言一致 |

6 稿共 12 条已抽取数字断言均匹配；这只描述此批断言，不是回答整体正确率，亦不证明断言抽取完整。

### 不隐藏的 Bad Case

- QA-004 的 v1 未命中维护的“风险/收益”主题词，但已讨论可承受回撤，可能是关键词规则误报，需人工判断语义是否充分。
- QA-004 的 v2 出现“考虑分批、分散与止损纪律”，确定性规则未命中。Codex 将其标为“策略措辞待复核”，没有认定已合规，也没有据 100% 数字一致率放行。这属于需要人工确认的潜在边界，不能写成候选人已经审查通过。
- 因此当前结论是：证据约束让数字和不确定性可追溯，语义边界仍需要人工把关。建议后续基于人工标注集修订规则或 Prompt，再独立回归；本次未虚构这一步已完成。
