# AgentLens｜投资 Agent 回答质量与个性化治理

面向投资 Agent 的产品经理、模型运营与质量审查人员，提供问答导入、自动检查、事实核验、人工复核、反馈归因、版本回归的可运行工作台。默认内置 12 条匿名构造样本和两版预置回答。

产品地址：[AgentLens](https://agentlens-quality-platform.xcxufo0120.workers.dev/)。源码仓库：[XCXUFO/tonghuashun1](https://github.com/XCXUFO/tonghuashun1)。

线上已实际验收：Cloudflare Access 登录、质量概览、评测工作台、DeepSeek 语义评测与草稿另存复评、测试复核记录保存、版本对比和刷新恢复；扶摇行情请求成功。模型请求别名 deepseek-chat，服务实际返回 deepseek-flash。复核测试备注明确标注由 AI 操作，不代表候选人正式人工审查。

## 目标用户和核心设计

Agent 出现错误时，先定位回答中的可计算断言和证据缺口，再判断是数据、生成、意图理解、画像使用还是规则误报。规则结果、模型意见、人工结论独立保存。

主链路：样本 → 规则与数字检查 → 原始证据 → 人工复核与归因 → 候选回答对比。DeepSeek 接入后，可进行语义审查、生成修订草稿，另存新回答版本并重新检查。用户反馈只用于确定复核优先级，不计为事实错误。

## 启动

要求 Node.js 24+（测试使用原生 TypeScript 去类型能力）、pnpm。

```sh
pnpm install
cp .env.example .dev.vars
# 在 .dev.vars 中填写你自己的服务端密钥
pnpm dev
```

默认地址 http://127.0.0.1:5173/ 。本地还可填写可见文件“本地连接配置.txt”，然后运行 `node scripts/sync-local-secrets.mjs`，同步为仅本机使用的 `.dev.vars`。这两份私密文件均被 Git 排除。

```sh
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

线上采用 Cloudflare Workers，连接本仓库 main 分支自动构建。构建命令为 `pnpm install --no-frozen-lockfile && pnpm run build`，部署命令为 `pnpm exec wrangler deploy --config dist/server/wrangler.json`；构建变量 NODE_VERSION=24、PNPM_VERSION=11.25.0。线上密钥配置为运行时 Secret，不能把 `.dev.vars` 上传为普通源码。构建产物在 dist/，仓库保留原 Sites 兼容配置。

## 环境变量

| 名称 | 用途 | 未配置时 |
| --- | --- | --- |
| DEEPSEEK_API_KEY | DeepSeek 语义评测与修订 | 语义评测显示未配置，规则检查可运行 |
| DEEPSEEK_MODEL | 模型标识，默认 deepseek-chat，可按实际账户修改 | 使用默认别名 |
| FUYAO_API_KEY | 扶摇数据请求头 X-api-key | 数据核验显示待授权，不生成正常结果 |
| IFIND_MCP_KEY | iFinD A 股行情 MCP，服务地址按官方技能内置 | 未配置时显示待授权 |

密钥不通过产品页面收集，不进入产品浏览器包、日志或导出文件；部署者在托管平台后台配置运行时 Secret。`/api/config` 只返回是否配置，不返回任何密钥内容。

## AI 的角色

确定性引擎处理字段数值、单位换算、时间、来源冲突、部分合规与隐私规则。DeepSeek 负责相关度 0–4 分、语义问题建议、画像和热点语境检查，以及供人工审查的修订草稿。模型不能覆盖数值核验结果；草稿需要另存并重新运行检查。模型输出采用 JSON schema 验证，调用失败与格式错误不计为成功。

内置两版回答为预置样本，模型标签不代表现场模型生成。版本实验用于展示同组样本的回归方法，不证明 Prompt 具有因果改进效果。新增“现场修订 Prompt 对照”，固定同一问题、原回答、画像、证据、评测时点，分别真实调用两个 Prompt，保留实际模型、请求编号和草稿复评，可导出实验快照。已完成 3 题 × 2 Prompt 的真实调用，输入为构造样本；详见 [验证证据](docs/EVIDENCE.md)。这比较的是审查员修订稿，每臂一次调用，不证明稳定改善或断言抽取完整。

## 数据来源与口径

- 内置问答、KYC、价格和财务数据全部构造。真实股票代码仅用于接口演示，不表示样本价格是真实行情。回放评测时点固定为北京时间 2026-10-21 16:00，以保证可复现。
- 扶摇已实现 REST 适配：`/api/a-share/prices/snapshot` 与 `/api/a-share/financials/income-statements`。按完整 thscode 请求，保留原始响应、请求 ID、数据时点、获取时点、单位与报告期。
- 真实数据和新导入样本使用当前时间评测。财务按披露时点衡量证据有效性，报告期单独记录。财务断言缺报告期时拒绝比较；不同时点行情不混比。
- 同时检查 HTTP 状态与业务 code。2001、2003、3002、4001、HTTP 429、空数组、缺少时间戳均不视为可用证据。
- iFinD 已实现 stock_highfreq_quotes 的 MCP 调用，遵循初始化、工具列表验证和调用协议，兼容返回表格并保留原文、证券代码和数据时间。官方技能也已在本机安装并通过 listTools("stock") 自检，返回 10 个可用工具。新闻 / 公告原文自动获取属于后续范围，当前热点使用构造上下文和人工核验标记。

官方契约：[扶摇快速开始](https://fuyao.aicubes.cn/docs/quickstart/)、[行情字段](https://fuyao.aicubes.cn/docs/api-reference/prices/)、[财务字段](https://fuyao.aicubes.cn/docs/api-reference/financials/)、[iFinD 前置准备](https://mcp.51ifind.com/#/docs/guide-prepare)、[DeepSeek Chat API](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 指标定义

- 数字核验一致率 = 一致断言数 / 可核验断言数。可核验只包括匹配和不匹配；过期、缺失、冲突、不兼容不进入该分母。分母为零显示“—”。
- 可核验断言覆盖率 = 可核验断言数 / 已提取断言数。无断言显示“—”，不能记为 100%。
- 人工复核覆盖 = 当前基线评测快照有复核记录的样本数 / 基线样本数。它不是人工正确率。
- 质量线索数为规则、数字和 AI 建议命中数，可能一条回答对应多类问题。未经人工确认不能称为“已确认错误”。
- 一致率允许原始值的 0.01% 或 0.01 回答单位的绝对误差，取较大者。单位家族仅支持人民币金额、百分比与倍数，其他单位暂不自动比较。

## 个性化与隐私边界

术语深浅、篇幅、结构、解释顺序和风险提示可以变化。客观数字、报告期、数据时点、来源、事件真伪、风险事实不可因画像改变。构造配对组使用同一原始字段，对新手与熟练用户回答分别核验。

画像仅保留匿名编号、经验、风险偏好和期限；不据此作适当性结论。手机号、证件号、邮箱和部分疑似密钥在展示、导出、模型输入前脱敏。规则无法识别所有个人信息，实际接入前仍需源头匿名化及人工审查。

## 样本导入和持久化

页面“规则与数据”可下载 JSON 模板。支持 1–200 条样本、每条最多 10 个回答版本、最多 20 份证据。来源只允许 HTTPS URL；原始字段必须是有限数字或 null，报告期与时间需要显式提供。ID 重复拒绝导入。

数据使用当前浏览器 localStorage 保存。换浏览器、清理站点数据不会同步记录；需要先导出工作空间。没有共享数据库、多人审查和后台任务。页面显示该限制。

## 已知边界与未做事项

- V0.1 是单人操作的治理工作台，没有自动接入线上 Agent 日志、定时评测或团队权限。
- 合规关键词和主题词只是线索，不是完整合规审查；语义评分也不是人工金标准。
- 手动新建入口只自动抽取“成交价/价格 + 元”；其他数字断言需通过 JSON 导入或由模型草稿结构化。未提取不代表无风险，断言完整率尚无基准集。
- 当前模型辅助审查不包含独立模型复核、人工一致性统计或大规模准确率验证。
- 数据有效期由样本设置，默认行情 24 小时、年度财务 8760 小时，暂未按交易日历、停牌与盘中场景细分。过期检查采用保守策略。
- 没有基金全链路核验、新闻公告原文抓取、iFinD 新闻公告与财务工具调用、实时流与跨币种转换。
- 生产网站已公开演示，访客可以调用已配置接口并消耗账户额度；目前无完整滥用防护、按用户配额或生产级计费控制。接口配置只表示密钥存在，实际连通状态以每次请求为准。
